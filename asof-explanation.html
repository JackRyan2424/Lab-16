1. Two dates answer different questions

Month measured identifies the period the price describes. Published on identifies when that price became available. A February observation published in April cannot be used for a March 31 decision. A revision is another publication for the same ticker and measured month.

The cutoff is inclusive: a publication dated March 31 is allowed. A publication dated April 1 or later is excluded.

4. Calculate and compare the signals

The signal is the price return from the previous calendar month to the latest month available in the panel:

Return (%) = (latest price / previous month's price - 1) × 100

The naive comparison still removes missing tickers and exact duplicates, but ignores the decision-date cutoff and selects the latest publication for each ticker and month.

5. How rule 4 works in the code

latest = {}
for row in rows:
    key = (row[1], row[2])
    if key not in latest or row[3] > latest[key][3]:
        latest[key] = row
  • latest = {} creates a dictionary to hold one selected record per ticker and month.
  • for row in rows: examines each eligible record.
  • key = (row[1], row[2]) groups by ticker and measured month, such as ("AAA", "2026-02").
  • The if condition accepts the first record for a group or replaces it when a later publication appears. ISO dates in YYYY-MM-DD format sort chronologically.
  • latest[key] = row stores the selected record, including its original row number.

The full function also rejects conflicting prices published on the same date for the same group and returns the chosen rows in source-row order.

For the as-of panel, this function receives only records that already passed the publication cutoff. AAA’s February price of 104 in row 2 is replaced by 103 in row 4, published March 25. CCC’s April 5 revision is excluded before this step, so row 12 remains available.

The exercise expects riskier credit at the same maturity to yield more and therefore cost less: AAA above BBB above CCC in price. CCC violates that ordering in both months. Prices above 100 imply negative yields, which the exercise flags as planted errors.

The four filtering rules check provenance and timing. They do not remove these economic anomalies. The sanity check is a separate review of the six surviving rows.

7. What look-ahead bias means here

Look-ahead bias is using information that was unavailable at the time of a decision. It can enter through a new observation published later or through a later revision of an earlier observation.

AAA’s naive return of +5.83% uses March’s price of 109, published on April 10. On March 31, that price was not yet knowable. The latest available month was February, whose revised price was 103. The available return was therefore +1.98%.

CCC shows the revision version of the same problem: February’s price of 112 was published April 5. Its measured month is before the cutoff, but its publication is after it. Using 112 instead of the available 111 changes the return from +0.91% to +1.82%.

Future information does not always improve the apparent return: BBB’s naive return is more negative. The issue is whether the information was available, regardless of whether it makes performance look better or worse.

If the decision date is changed to April 10, 2026, all supplied publications become eligible, and the as-of signals match the naive signals for this dataset.
